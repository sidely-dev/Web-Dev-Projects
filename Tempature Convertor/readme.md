## 📖 About The Project

### What is this project?

> This project is an interactive, responsive mathematical frontend application built using pure HTML5, CSS3, and modern JavaScript that takes numeric input values and immediately maps conversions across three major global scale units simultaneously.

### Why did I build it?

This project was created to:
- Practice bi-directional data tracking loops, ensuring that mutating any single scale input instantly updates the adjoining unit modules.
- Solve floating-point rounding precision hurdles native to computer architectures within strict calculation loops.
- Design dynamic visual feedback interfaces where dashboard layouts alter color values based on extreme heat or freezing parameters.

### Project Background

This is a functional portfolio calculator and mathematical learning project deployed to master rapid state data updates, numerical data sanitization, and clean interface structures.

---

## 🎯 Project Objectives

The main objectives of this project are:

- [x] Establish an absolute zero-latency input translation engine.
- [x] Implement robust validation workflows to clean strings and filter out non-numeric characters.
- [x] Standardize calculations to uniform floating decimal outputs (e.g., locking to two decimal places).
- [x] Create a completely responsive interface tailored for simple mobile and desktop lookups.

## ✨ Features

### ✅ Implemented Features

- **Tri-Scale Synchronization Matrix** — Enter values into Celsius, Fahrenheit, or Kelvin inputs to watch the other two fields update instantly.
- **Dynamic Thermal Color Coding** — The user interface contextually alerts users by transitioning background shades to warm oranges during hot calculations and frosty blues during sub-zero conversions.
- **Precision Lock Engine** — Automated mathematical normalization layers locking calculations to a clean 2-decimal limit, preventing long fractional trailing sequences.
- **Absolute Zero Guardrail** — Built-in logic blocks that flags invalid inputs falling below absolute baseline limits (-273.15°C or 0K).

### 🚧 Features Currently Being Developed

- **Historical Computation Log** — Building an in-session visual sidebar feed keeping tabs on past conversions generated by the user.

### 🔮 Planned Features

- [ ] **Extended Scientific Scales** — Integrating less common metric structures like Rankine and Réaumur systems for full scientific functionality.

## 🚀 Getting Started

Review the parameters below to spin up this mathematical utility on your local test frame.

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd temperature-converter
   ```

2. **Boot the project**

### Usage

1. Open `src/index.html` inside your internet explorer or favorite web dashboard browser.
2. Type a numeric metric value into any input card slot.
3. Observe the adjoining panels reflect matching updates immediately across every alternative matrix scale.

## 🐛 Bugs & Fixes

- **Bug:** Inputting negative integers caused structural calculation drops within early conditional loops.
- **Fix:** Restructured text validation rules to allow leading negative symbols (`-`) through regex filtration sweeps before running calculations.

---

## 💡 Challenges & Struggles

The central logic difficulty involved avoiding infinite operational loops. Because modifying an input triggers calculations across its neighboring nodes, structural verification states had to be carefully isolated so that an automated calculation didn't fire backward onto the actively targeted input element.
